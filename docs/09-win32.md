# MyOS — Capa Win32 (PE32 + DLLs ring 3 + CRT)

Archivos: `kernel/pe.c|h`, `kernel/elf.c|h`, `kernel/win32.c|h`,
`user/win32/*.c`, `tools/makepe.py`, `tools/dll32.ld`, `tools/user.ld`.

## 1. Loader PE32 (`kernel/pe.c`)

- Detecta por magia: `MZ` → PE, `\x7FELF` → ELF (shell `run` y
  `SYS_EXEC` usan el mismo camino dual).
- Valida MZ/PE, recorre **secciones** (`SizeOfRawData` a 0x80000000+,
  página por sección) y cabecera MZ raíz (página 0 con los primeros bytes
  del archivo; el runtime relocator de mingw inspecciona `e_lfanew`).
- **Imports estándar** (`IMAGE_IMPORT_DESCRIPTOR` + IAT): convierte cada
  RVA `oft + j*4` con `pe_rva_to_off` (validando contra el tamaño; los
  RVAs mingw superan el EOF), resuelve contra la tabla de exports
  (case-insensitive) y escribe la VA en el slot de la IAT. El formato
  `.idata` viejo (makepe.py) queda como fallback.
- Los slots de la IAT se escriben con `paging_user_frame` (vaddr
  alineado a página; `va & ~0xFFF`).
- `.bss`: se mapea `p_memsz` (más grande que `p_filesz`).

## 2. DLLs fijadas en ring 3 (`kernel/win32.c`)

Decisión de diseño: las DLLs son **ELF32 enlazados a bases fijas** en la
región 0xB0000000-0xB3FFFFFF (1 MiB cada una), con una tabla `.exports`
(nombre → VA absoluta). El kernel las lee del FS en `win32_init()` y las
mapea a **cada** PD de usuario en `win32_map_all()`:

| DLL | Base | Arduino |
|-----|------|---------|
| `kernel32.dll` (kernel32.elf) | 0xB0000000 | Proceso, archivos, heap, TIB/CRT |
| `user32.dll` (user32.elf) | 0xB1000000 | MessageBoxA + widgets MyOS |
| `ntdll.dll` (ntdll.elf) | 0xB2000000 | RtlZeroMemory/CopyMemory, GetModuleHandle |
| `msvcrt.dll` (msvcrt.elf) | 0xB3000000 | CRT completo (printf, malloc, exit...) |

`win32_resolve("dll", "func")` busca en las tablas exportadas.

## 3. TIB y CRT mingw

- Selector GDT 0x30 (RPL3 0x33) con base = `WIN32_TIB_VA` 0x84000000;
  `win32_tib_map()` rellena la página USER por tarea (`Self` en
  `%fs:0x18`, StackBase/StackLimit). El TIB guarda también la **línea de
  comandos** (`WIN32_TIB_CMDLINE_OFF` 0x100, 128 B) — base de
  `GetCommandLineA` → `__getmainargs` → `argc/argv`.
- **Retorno del CRT**: `mainCRTStartup` termina en `_crt_ret` de msvcrt
  (lee `eax` = main() y llama a `SYS_EXIT`). Se fija
  `USER_ESP0_INIT = 0xBFFFFF8` y `win32_crt_ret_init()` escribe la VA por
  `paging_user_frame` al crear la tarea y en `SYS_EXEC`.

## 4. Exportaciones por DLL

**kernel32** (~40 exports): proceso (GetCurrentProcessId, ExitProcess,
GetModuleHandleA/FileNameA, GetCommandLineA/W, GetProcAddress,
LoadLibraryA, IsDebuggerPresent, Sleep, GetTickCount, GetLastError,
Virtual*Alloc/Protect/Query, GetProcessHeap/Heap*, GetStartupInfoA),
archivos (CreateFileA, ReadFile, GetFileSize, CloseHandle, FindFirst/
Next/Close), consola (GetStdHandle, WriteFile), TIB/CRT helper
(InitializeCriticalSection*, Tls*, SetUnhandledExceptionFilter,
MultiByteToWideChar, WideCharToMultiByte, GetCPInfo, GetSystemTimeAsFileTime
...).

**msvcrt** (~40 exports): `__getmainargs`, `__p__iob`, `printf`/`vfprintf`
(con anchos/flags), `puts/putchar/fputs/fputc/fprintf/fwrite/fflush`,
`malloc/calloc/realloc/free`, `exit/atexit/_cexit/_amsg_exit/abort`,
`memcpy/strlen/strncmp/wcslen`, `signal/strerror/localeconv/setvbuf`,
`_errno`, `_initterm`, `_lock/_unlock`, `_crt_ret`.

**user32** (5 exports): `MessageBoxA`, `MyOS_PollEvent`, `MyOS_DrawButton`,
`MyOS_WidgetHit`, `MyOS_ButtonFeed` (mini-API de widgets de la Fase 15).

**ntdll** (5 exports): `RtlZeroMemory`, `RtlCopyMemory`,
`RtlWow64GetProcessMachines`, `GetModuleHandle`, `RtlGetNativeSystemInfo`
(según versión).

## 5. Ladder de compatibilidad (WIN32_COMPAT_LADDER.md)

2. `quick.exe` — PE MyOS mínimo (2 syscalls)

4. `hello_win.exe` — mingw real (CRT, printf/puts/malloc)

6. `fork.exe` — fork + exit

12-13. `messagebox.exe` — GUI: abre ventana y cierra con Enter (IDOK=1)
14. `mouseinfo.elf` — SYS_MOUSEINFO + SYS_EVENT

## Reglas y bugs clave

- Shims freestanding: sin libc del host; todo determinista.
- API no implementada → valor de fallo plausible, nunca crash del kernel.
- Números de syscall hardcodeados en shims deben coincidir con
  `kernel/syscall.h` (bug: malloc usaba 11 → NULL → `_amsg_exit(8)`).
- `GetModuleHandleA(NULL)` devuelve `KERNEL_BASE` (mentira blanca: los
  exe suelen llamarla para averiguar su propia base); `LoadLibraryA` solo
  acepta los 4 nombres conocidos.
- El module mapeo copia solo `p_offset..p_offset+p_filesz`, el resto del
  `p_memsz` a 0.
- IAT por RVA: cada slot se convierte con `pe_rva_to_off(oft + j*4)`.
